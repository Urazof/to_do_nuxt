## Выполненные задачи

### 1. Создана модель User с полями:
- ✅ `email` (String, required, unique, lowercase, trim, indexed)
- ✅ `password` (String, required, minlength: 6) - хешируется автоматически перед сохранением
- ✅ `createdAt` (Date) - автоматически через timestamps
- ✅ `updatedAt` (Date) - автоматически через timestamps

**Файл:** `server/models/User.ts`

**Особенности:**
- Автоматическое хеширование пароля через bcrypt (10 раундов) в pre-save хуке
- Метод `comparePassword()` для безопасного сравнения паролей
- TypeScript интерфейс `IUser` для типизации
- Индекс на поле `email` для быстрого поиска пользователей

### 2. Добавлено поле userId в модель Todo:
- ✅ `userId` (ObjectId, ref: 'User', required, indexed)
- ✅ Связь с коллекцией User через референс

**Файл:** `server/models/Todo.ts`

**Особенности:**
- TypeScript интерфейс `ITodo` для типизации
- Валидация максимальной длины title (500 символов)
- Индекс на поле `userId` для быстрого поиска задач пользователя
- Индекс на поле `isDone` для фильтрации по статусу

### 3. Созданы индексы для оптимизации запросов:

#### User индексы:
- `email` (unique, indexed) - для поиска пользователя при логине

#### Todo индексы:
- `id` (unique) - первичный ключ
- `userId` (indexed) - для выборки всех задач пользователя
- `isDone` (indexed) - для фильтрации по статусу
- `{userId: 1, createdAt: -1}` (compound) - для пагинации и сортировки задач пользователя
- `{userId: 1, isDone: 1}` (compound) - для фильтрации выполненных/невыполненных задач

> **Примечание:** Модель **Session** будет создана на **Этапе 2** при реализации JWT авторизации. Она будет использоваться для хранения refresh токенов и управления активными сессиями пользователей.

## Преимущества реализации:

1. **Производительность:**
   - Составные индексы обеспечивают быструю выборку задач конкретного пользователя
   - Индексы на email ускоряют процесс аутентификации
   - Правильная индексация готова для масштабирования

2. **Безопасность:**
   - Пароли хешируются автоматически с помощью bcrypt
   - Защита от SQL injection благодаря Mongoose
   - Валидация на уровне схемы

3. **Масштабируемость:**
   - Правильная индексация позволяет эффективно работать с большими объёмами данных
   - Разделение данных по пользователям предотвращает утечки информации

4. **Типизация:**
   - Полная TypeScript типизация всех моделей
   - DTO для валидации входных/выходных данных
